Wildcard Mask Reference

A wildcard mask is the inverse of a subnet mask: a 0 bit means "this bit must match", a 1 bit means "don't care". Subtract each octet of the subnet mask from 255 to get it.

Two shorthands mean exactly the same thing as a wildcard: host 192.168.30.3 is 192.168.30.3 0.0.0.0, and any is 0.0.0.0 255.255.255.255.

Why the placement rule differs. A standard ACL can only see where a packet came from, so filtering it early would block that source from reaching everything, not just the one network you meant to protect. An extended ACL knows the destination too, so it can be applied early and drop unwanted traffic before it crosses the network.

Order matters. ACEs are checked top to bottom and the first match wins — nothing after it is considered. A broad permit above a specific deny makes that deny unreachable.

There is always an implicit deny any at the end of every ACL, so anything not explicitly permitted is dropped. Adding an explicit deny any changes nothing functionally, but it shows up in show access-lists with a match counter, which is genuinely useful when troubleshooting.

An ACL applied to an interface filters traffic passing through the router. An ACL applied to the vty lines with access-class filters traffic to the router itself — who is allowed to log in.
