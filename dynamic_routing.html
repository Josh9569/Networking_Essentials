OSPF Cost Reference

OSPF cost is reference bandwidth ÷ interface bandwidth, rounded down, with a minimum of 1. The default reference bandwidth is 100 Mbps, which is why every link at or above 100 Mbps lands on cost 1 until auto-cost reference-bandwidth is raised. Cost accrues on the outgoing interface of each hop — including the last router's link to the destination network.

RIP Reference

RIP's metric is hop count and nothing else — bandwidth, delay and link type never enter into it. A router adds 1 to whatever metric it was advertised, 16 means unreachable, and so the network can be at most 15 hops across. Equal metrics are load-balanced, up to four paths by default. Administrative distance is 120.

RIP Command Reference

Everything the lab needs, in the order you would type it. network takes a classful address — IOS rounds whatever you type down to its major network, then runs RIP on every interface whose address falls inside it. One statement can therefore cover several interfaces at once.

CommandModeWhat it does
router ripconfigStart the RIP process and enter router-configuration mode
version 2config-routerSend and receive RIPv2. v1 and v2 do not interoperate
network 10.0.0.0config-routerRun RIP on every interface in that major network, and advertise it
no auto-summaryconfig-routerStop summarising to the classful prefix at a major-network boundary. Needs version 2 — v1 carries no masks, so it has no choice
passive-interface Gi0/0config-routerStop sending updates out that interface. It still receives, and the network is still advertised to others
no network 209.165.200.0config-routerStop advertising a network. Useful when a classful statement has swept in more than you meant — an ISP link, say
ip route 0.0.0.0 0.0.0.0 ifaceconfigA default route: where to send anything the table has no better match for. Pointing it at a loopback is the usual way to stand in for the Internet
default-information originateconfig-routerAdvertise that default route to the RIP neighbours, so they get 0.0.0.0/0 too. It does nothing until a default route exists
ip address ip maskconfig-ifAddress the interface (dotted mask, not CIDR)
no shutdownconfig-ifBring the interface up
show ip routeexecThe routing table. RIP routes show as R with [120/hops]
show ip protocolsexecVersion, whether auto-summary is in effect, which interfaces run RIP, and the networks advertised
show ip interface briefexecAddress and up/down state of every interface
show runexecThe configuration as it currently stands

In show ip route, a connected network is C, a RIP route is R with [120/hops], your own default route is S*, and a default learned from a neighbour is R*. The gateway of last resort line at the top says whether the router has a default at all.

Stub blocks Type 5, and so Type 4 with it. Totally stubby blocks those plus every Type 3 except a single default route. NSSA blocks Type 5 but allows its own ASBR to inject Type 7.
