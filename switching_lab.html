VLAN / Trunk Reference

      
    
        
  • 1
    
          An access port belongs to exactly one VLAN and connects end devices (PCs).
          Frames on it are untagged — the switch tracks the VLAN internally.
          
    switchport mode access · switchport access vlan 10
    
        
    • 
        
  • 2
    
          A trunk port carries multiple VLANs between switches using 802.1Q tags.
          Both ends of the link must be trunks or traffic will not pass correctly.
          
    switchport mode trunk
    
        
    • 
        
  • 3
    
          Two PCs can only communicate at Layer 2 if they are in the same VLAN
          and every switch-to-switch link on the path carries that VLAN.
        
    • 
        
  • 4
    
          EtherChannel bundles multiple physical links into one logical link
          (more bandwidth, no STP blocking between them). Every member port on a switch must share the
          same channel-group number and the same trunk settings as its port-channel
          interface, or it is suspended. The two ends must agree on a mode: LACP
          (active with active or passive), PAgP
          (desirable with desirable or auto), or on at both
          ends. passive+passive and auto+auto never bundle.
          
    channel-group 1 mode active · interface port-channel 1
    
        
    • 
        
  • 5
    
          A trunk carries every VLAN until you restrict its allowed list. A VLAN
          missing from the list at either end does not cross the link. Use add to extend the list
          without retyping it — a bare list replaces what was there.
          
    switchport trunk allowed vlan 10,20 · switchport trunk allowed vlan add 99
    
        
    • 
        
  • 6
    
          Port security limits which MAC addresses an access port accepts. Addresses are learned
          from traffic (or typed in); sticky writes learned ones into the running config. A frame from
          one address too many is a violation: shutdown (the default) err-disables
          the port, restrict drops and counts it, protect drops it silently. An
          err-disabled port only recovers with shutdown then no shutdown.
          
    switchport port-security · switchport port-security mac-address sticky

STP Rules

      
    
        
  • 1
    
          Root bridge election: the switch with the lowest bridge ID wins.
          Bridge ID = priority + MAC address. Compare priority first; if tied, the lowest MAC wins.
        
    • 
        
  • 2
    
          Every non-root switch picks one root port — the port with the lowest
          total path cost to the root (FastEthernet link = cost 19).
        
    • 
        
  • 3
    
          Each link segment gets one designated port — the end whose switch has the
          lower path cost to the root; ties are broken by lower bridge ID. All root-bridge ports are designated.
        
    • 
        
  • 4
    
          Any port that is neither a root port nor a designated port becomes blocking —
          this breaks the loop. In a triangle of switches exactly one port blocks: on the redundant link,
          the end belonging to the switch with the higher bridge ID.
        
    • 
        
  • 5
    
          Priorities can also be set with keywords: root primary configures priority
          24576 and root secondary configures 28672,
          both lower (better) than the default 32768. Lower always wins the election.
          
    spanning-tree vlan 1 root primary

Command Reference

      
The CLI accepts Cisco IOS syntax with standard abbreviations (e.g. conf t, int fa0/1, sw mo ac). Commands work at any prompt level for convenience. Press Tab to auto-complete keywords and use the ↑ / ↓ arrow keys for command history.

      

        
          
configure terminalEnter config mode (conf t)

          
vlan <n>Create VLAN n and enter config-vlan mode

          
name <text>Name the VLAN (from config-vlan mode)

          
interface fa0/<n>Select a port (int fa0/1)

          
switchport mode accessMake the port an access port (sw mo ac)

          
switchport access vlan <n>Assign VLAN (sw ac vl 10)

          
switchport mode trunkMake the port a trunk (sw mo tr)

          
interface range fa0/<a> - <b>Select several ports at once (int ra fa0/1-2)

          
shutdown / no shutdownDisable / enable the selected port (or SVI)

          
channel-group <n> mode active|passive|desirable|auto|onAdd port to EtherChannel n (LACP / PAgP / static)

          
interface port-channel <n>Configure the bundle itself — changes apply to every member

          
switchport trunk allowed vlan <list>Set the VLANs a trunk carries (add / remove / all / none)

          
switchport port-securityTurn on port security (access ports only)

          
switchport port-security maximum <n>How many MAC addresses the port may hold

          
switchport port-security mac-address stickyLearn addresses into the running config

          
switchport port-security mac-address <H.H.H>Add a static secure address

          
switchport port-security violation shutdown|restrict|protectWhat a violation does

          
clear port-security sticky|dynamic|all [interface fa0/<n>]Forget learned secure addresses

          
no switchport access vlanReturn port to VLAN 1

          
switchport trunk native vlan <n>Set the trunk's native (untagged) VLAN

          
no channel-groupRemove from EtherChannel

          
show vlan briefShow VLAN → port table

          
show runShow this switch's port config

          
show interfaces statusEvery port: connected / notconnect / disabled / err-disabled, and its VLAN

          
show interfaces trunkTrunking ports, native VLAN and allowed list

          
show interfaces fa0/<n> switchportOne port's mode, access VLAN, native VLAN and allowed list

          
show etherchannel summaryEach bundle, its protocol and member flags (P bundled, I stand-alone, s suspended, D down)

          
show port-security [interface fa0/<n> | address]Secure ports, learned addresses and violation counts

          
show ip interface briefUp/down state of every port and the SVI

          
interface vlan <n>Enter SVI config, for the switch management IP

          
ip address <ip> 255.255.255.0Set the management IP on the SVI

          
ip default-gateway <ip>Where the switch sends traffic for other subnets (the router, .1)

          
clearClear the terminal display (config is kept)

          
spanning-tree vlan <n> root primarySet this switch's priority to 24576 (favoured as root)

          
spanning-tree vlan <n> root secondarySet this switch's priority to 28672 (backup root)

          
spanning-tree vlan <n> priority <val>Set an exact priority (multiple of 4096, 0–61440)

          
show spanning-treeShow this switch's root status and port roles (root/designated/blocked)

          
exit / endGo up one level / back to exec
